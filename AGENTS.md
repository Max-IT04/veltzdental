# AGENTS.md — VeltzDental

Общая информация по проекту для агентов (и для меня самого). Обновляй этот файл, когда меняются ключевые решения.

## Что это за проект

Одностраничный сайт (лендинг) частной стоматологической клиники VeltzDental. У клиники есть главный врач (клиника, судя по всему, названа в честь него). Заказчик просил **простой лендинг**.

**Главная цель сайта:** посетитель оставляет имя и телефон → администратор перезванивает и записывает на приём.

## Согласованные решения

| Вопрос | Решение |
|---|---|
| Тип сайта | Лендинг (одна страница, якорная навигация) |
| Стек | Чистые HTML/CSS/JS, без фреймворков и сборщиков |
| Заявки | Formspree (бесплатный тариф), заявки на email администратору |
| Карта | Яндекс Карты (вставка iframe из конструктора) |
| Хостинг | GitHub Pages |
| Дизайн | Современный минимализм: белый фон, много воздуха, крупная типографика |
| Контент | Пока заглушки, реальный контент появится позже |
| Будущее | Возможна миграция на YClients — форма должна легко заменяться |

## Структура проекта

```
VeltzDental/
├── index.html           — вся разметка (все секции лендинга)
├── privacy.html         — политика конфиденциальности (заглушка-структура по 152-ФЗ)
├── terms.html           — условия использования сайта
├── refund.html          — политика возврата средств
├── cookie-policy.html   — политика использования cookie
├── styles.css           — все стили, переменные в :root
├── main.js              — бургер-меню, валидация и отправка формы, баннер cookie, год в футере
├── first-plan.md        — декомпозированный план работ с текущими статусами
├── AGENTS.md            — этот файл
└── assets/              — сюда позже положим фото (врач, работы до/после)
```

## Как запустить локально

Вариант 1 — просто открыть `index.html` двойным щелчком в браузере.

Вариант 2 — локальный сервер (нужен для тестирования отправки формы):

```powershell
python -m http.server 8000
# затем открыть http://localhost:8000
```

## Заглушки, которые нужно заменить на реальный контент

- Телефон `+7 (000) 000-00-00` — в шапке, футере и контактах (3 места в index.html + 4 юридические страницы)

- Юридические страницы (privacy/terms/refund/cookie) — структура готова, текст должен проверить юрист

## Конвенции кода

- Весь контент — на русском языке
- Никаких внешних JS/CSS-библиотек (единственное исключение — шрифт Inter через Google Fonts)
- Все цвета, радиусы, отступы — через CSS-переменные в `:root` в styles.css
- Семантическая разметка: `header`, `section`, `nav`, `footer`; навигация по якорям (`#services`, `#doctor` и т.д.)
- Адаптивность обязательна: брейкпоинты 960px и 720px
- Не добавлять фреймворки, сборщики и зависимости без явного согласования с заказчиком
- Юридические правила: никаких тёмных паттернов; отзывы и регалии — только реальные и подтверждённые; изображения — только свои или лицензионные (с согласием пациентов для работ «до/после»)
- План работ ведём в first-plan.md: выполнили задачу — отмечаем `[x]`

## Процесс работы

Итеративный. Порядок: берём следующую незакрытую задачу из first-plan.md → обсуждаем, если нужно → делаем → проверяем в браузере → отмечаем выполненной. Крупные изменения дизайна и структуры согласуем до правок.
