# first-plan.md — план работ по сайту VeltzDental

Создан по итогам опроса заказчика. Двигаемся по этапам сверху вниз, отмечаем выполненное.

## Сводка ТЗ (из опроса)

- Лендинг частной стоматологии с главным врачом, простой
- Цель: посетитель оставляет имя и телефон, администратор перезванивает
- Заявки через Formspree (позже возможна миграция на YClients)
- Разделы: главный экран + запись, услуги и цены, врач, отзывы и работы, контакты + Яндекс Карта
- Стек: чистые HTML/CSS/JS
- Дизайн: современный минимализм
- Хостинг: GitHub Pages
- Контента пока нет — везде реалистичные заглушки

## Этап 2. Подключить Formspree (~30 минут)

Цель: заявки из формы реально приходили на email администратору.

1. Зарегистрироваться на https://formspree.io (бесплатно)
2. Нажать «New form», указать email администратора — туда будут падают заявки
3. - [x] Скопировать ID формы из адреса вида `https://formspree.io/f/xxxxxxx`
4. - [x] В `main.js` вписать ID: форма `mjyydpry` уже подключена
5. - [ ] Отправить тестовую заявку с сайта и убедиться, что письмо пришло администратору
6. - [ ] Форма отправляет заявки на email

> Важно: на бесплатном тарифе Formspree — 50 заявок в месяц. Если будет больше, перейдём на платный тариф или другой сервис.

> Если после вставки ID всё ещё виден красный текст «Форма ещё не подключена» — это кэш браузера: обновите страницу жёстко, **Ctrl+F5** (или откройте сайт через локальный сервер `python -m http.server 8000`).

## Этап 3. Яндекс Карта (~20 минут)

1. Открыть https://yandex.ru/map-constructor/, найти адрес клиники
2. Настроить вид карты, нажать «Получить код карты»
3. Скопировать HTML-код (iframe)
4. В `index.html` в секции «Контакты» заменить `<div class="map-placeholder">…</div>` на этот iframe
5. - [ ] Интерактивная карта на месте

## Этап 7. Публикация на GitHub Pages

1. Создать аккаунт на github.com (если нет)
2. Создать репозиторий `veltzdental`
3. Выполнить git-команды (помогу):
   ```powershell
   git init
   git add .
   git commit -m "Initial landing"
   git remote add origin https://github.com/USERNAME/veltzdental.git
   git push -u origin main
   ```
4. Settings → Pages → Source: `main` branch
5. - [ ] Сайт открыт по адресу `username.github.io/veltzdental`
